Marketing deck screenshots — drop your high-fidelity PNG/JPG captures here.

The /marketing-slides deck binds each feature frame to these EXACT paths:

  /marketing/dashboard.png   → لوحة التحكم (Dashboard + interactive geo-map)
  /marketing/weather.png     → صفحة الطقس (recalibrated Weather page)
  /marketing/copilot.png     → مساحة Copilot (multi-agent chat workspace)
  /marketing/fields.png      → حقولي (Fields / GIS map)
  /marketing/crops.png       → المحاصيل (Crops module)
  /marketing/market.png      → لوحة السوق (Market insights)

Tips:
- File names are case-sensitive and must match exactly (lowercase, .png).
- Recommended capture ratio ~16:10 (e.g. 1600×1000) — images are clipped
  with object-cover object-top, so wider/taller shots crop gracefully from the top.
- .png is assumed; if you prefer .jpg, rename the files OR update the
  `image:` paths in src/app/marketing-slides/page.tsx.
